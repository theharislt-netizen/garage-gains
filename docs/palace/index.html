The installed app is a real Android APK — the same kind of file as RIGCORE — not Add to Home Screen. Use this for the native phone build.

Download Android app

On the phone: allow Install unknown apps, open PALACE.apk, tap Install. After that, code updates arrive when you reopen the app.
